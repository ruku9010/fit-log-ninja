## Project Name : Fit Log ninja

## Short Describtion
It's a daily exercise plan project. Users can plan their workout routine. Users can learn about daily exercise and motivate.

## Technologies Used
NEXTJS | REACT | TAILWINDCSS | JAVASCRIPT | CSS | HTML | REACT-TOASTIFY | DAISYUI | REACT-ICONS

## 5 Key Features
1. Users can view each exercise and learn details
2. Users can add exercise for everyday's workout plan. 
3. Users can save their favorite exercise.
4. Users can count how many exerise they selected.
5. All the selected item they can store in a single page.
